# showcase-fastapi

A repo to learn and test FastAPI.

## Set up Python virtual directory

-   (root directory of this project)
-   `python -m venv .venv`
-   (Linux/Mac) `source .venv/bin/activate`
-   (Windows with bash) `source .venv/Scripts/activate`
-   (Windows command line) `.venv\Scripts\activate`
-   `pip install -r requirements.txt`

## Install dependencies

- `pip install -r requirements.txt`

## Start server

- `python server.py`

## Test server

- install VSCode [REST Client](https://marketplace.visualstudio.com/items?itemName=humao.rest-client) extension
- in **test.rest** click "Send Request"
